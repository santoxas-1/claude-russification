# Маршрут проверки русификации

Этот список — план ручной проверки, а не свидетельство её выполнения. Статус реального установленного приложения: **не проверено после обновления**. Закрытие и перезапуск согласуются отдельно.

## Обязательные экраны со скриншотов

- [ ] Коннекторы → постоянные разрешения MCP: заголовок, краткое описание, все абзацы развёрнутой справки.
- [ ] Срок действия разрешений запланированных задач: названия кнопок, ограничения, различия Cowork и Code, приоритет `toolPolicy`.
- [ ] Управляемые MCP-серверы: HTTP/SSE, stdio, OAuth, шаблоны имён инструментов, приоритет `blocked > ask > allow`.
- [ ] Возможности → встроенные инструменты: политика, запрещённые инструменты, поле необязательной области действия.
- [ ] Подключение → режим шлюза: вся справка вокруг `CLAUDE_CODE_USE_GATEWAY` и `skipWebFetchPreflight`.
- [ ] Тайм-аут потокового ответа: оба абзаца вокруг `CLAUDE_STREAM_IDLE_TIMEOUT_MS`, SSE и сообщения об ошибке сжатия.
- [ ] Модели → обнаружение: весь абзац о фиксированном списке и псевдонимах.
- [ ] Модели → контекст 1M: справка вокруг `inferenceModels`, `supports1m`, `prefer1m`.
- [ ] Редактор модели: ID, отображаемое имя, вариант 1M, псевдоним уровня, модель по умолчанию, максимальный уровень рассуждений.
- [ ] Модель по умолчанию для новых задач: вся справка и поведение сохранённого выбора.
- [ ] Экспорт: подписи и описания JSON, ADMX, plist, копирования без конфиденциальных данных.

## Остальной интерфейс

- [ ] Настройки: вкладки, поиск, пустые состояния, ошибки валидации, подсказки и доступные названия элементов.
- [ ] Плагины и каталоги: установка, ограничения организации, разрешённые и запрещённые серверы.
- [ ] Телеметрия: экспорт трассировок, аутентификация коллектора, сообщения об ошибках.
- [ ] Chat / Cowork / Code: меню, диалоги, создание и завершение задач, боковые панели.
- [ ] Нативные меню и диалоги Windows.
- [ ] Onboarding и состояния, доступные только при определённом подключении или политике: отметить недоступные, не считать автоматически проверенными.

## Проверки сохранности

- [ ] `bearer`, `x-api-key`, ID моделей, пути, JSON-ключи, имена веток и расширения файлов не изменены.
- [ ] Ссылки и кнопки работают; встроенный код не исчезает, React не сообщает об ошибках после повторного раскрытия карточек.
- [ ] Текст пользовательских сообщений, ответов, терминала и редактора не переводится.
- [ ] Названия команд сохраняются в списке команд, но обычные подписи Export / Plugins / Help переводятся.
- [ ] После динамического обновления и повторного открытия справки английские фрагменты не возвращаются.
- [ ] Отчёт сканера не содержит секретов и не считает технические идентификаторы ошибками перевода.

## Фиксация результата

Для каждого непроверенного или непереведённого элемента записать: версия приложения, экран, исходная фраза без секретов, способ воспроизведения и причина исключения. Наличие перевода в словаре не заменяет проверку отрисованного экрана.
